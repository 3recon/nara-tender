# AI 기반 공공입찰 SaaS 창업 아이디어 정리 (2026-10-28)

## 1. 문제 인식
- 나라장터는 회사 조건(면허·지역·금액)에 맞는 공고만 걸러보기 어려움
- 공고 목록 단계에서 "참여 가능한 것만" 필터링이 안 됨

## 2. 기존 해결 방법
- **외부 알림 서비스**: 공고공고(무료 앱, 첨부 검색·맞춤 알림), 비드프로 등 유료 서비스
- **공식 API**: 공공데이터포털 '조달청 나라장터 입찰공고정보서비스'(15129394)
  - 무료 인증키, 개발계정 일 1,000건 제한
  - 공고명 검색은 단순 부분일치 → 노이즈 많음 (제외어 필요)

## 3. 기존 AI 입찰 분석 도구
| 도구 | 기능 |
|---|---|
| 고비드(GOBID) | 적합 공고 선별, 참여 가능 여부, 투찰가 제안 (공사 중심) |
| 인공지능입찰연구소 | 맞춤공고, 낙찰하한가 예측(비드봇) |
| 클라이원트 | 공공입찰 빅데이터 시장 분석 (용역·IT) |
| 산군 | 업체별 투찰금액·개찰 결과 조회 |
| 크몽 맞춤 구축 | 면허·지역 맞춤 판정, AI 제안서 초안 |

- 투찰가 예측은 적격심사·최저가 입찰에 유효, 협상계약 용역은 제안서가 승부처
- 조달청도 AI 기능 개발 중 (2027년 지능형 공공조달 플랫폼 목표)

## 4. 경쟁력 판단
**어려운 점**
- 데이터 공개 → 진입장벽 낮음, 검색·알림은 차별화 불가
- 투찰가 예측은 선점 업체 강세
- 조달청 기본 기능 무료화 가능성

**기회**
- 첨부문서(제안요청서·과업지시서) LLM 분석 기반 자격 판정
- 제안서 작성 지원
- 성패는 기술보다 첫 고객 확보(영업)

## 5. 확보해야 할 데이터
1. 첨부문서 원문 (HWP/PDF 파싱) — 최우선
2. 사전규격·발주계획, 개찰·낙찰·계약 결과
3. 나라장터 외 공고 (자체 조달시스템, 기관 홈페이지)
4. 판정 기준 (물품분류번호, 업종코드, 경쟁제품 목록, 적격심사 기준 등)
5. 고객 회사 정보 (면허, 인증, 실적, 신용등급)
6. 사용 피드백 (참여/패스/결과) — 가장 강한 해자

→ 1~3은 기본기, 4~6이 차별점

## 6. 중소기업이 수익을 볼 수 있는 정부 사업
- 공공조달 / 정부 R&D / 바우처 / 정책자금 / 고용지원금·세제 / 인증 혜택
- 2026년 지원사업은 인증 보유 여부를 주요 심사 요소로 반영
- 지원사업도 "공고 분산 + 자격 판정 복잡" 구조 → 같은 엔진으로 확장 가능

## 7. 방향 결정
- **형태**: 개인 사이드 프로젝트(창업), 모든 중소기업 대상 웹 SaaS
- **강점**: SW 기술 (도메인 지식은 없음)
- **전략**: 범용으로 가되 쐐기 기능 하나로 진입

### 쐐기 기능: "공고 해석기"
> 공고 링크 붙여넣기 → AI가 참가자격·핵심요건·마감·제출서류 1장 요약 → 회사 정보와 비교해 가능/불가/확인필요 표시

- 가입 없이 무료 체험 → 진입장벽 최소화
- LLM이 요건 추출 → 업종별 로직 없이 범용성 확보
- 이후 유료 기능: 맞춤 알림, 제안서 초안
- 엔진은 업종 무관 설계, 반응 좋은 업종부터 깊게

## 8. 리스크 체크
- 회사 겸업 규정 확인, 회사 자료 사용 금지
- API 운영계정 전환 필요 (트래픽)
- 판정 오류 책임 → 최종 확인은 고객 몫 고지
